# Smart Traffic Light Simulator 🚦

## Overview

A Java-based Smart Traffic Light Simulator that manages traffic flow at an intersection using data structures and priority-based vehicle handling. The system can prioritize emergency vehicles and send alerts through Telegram.

## Features

* Traffic light simulation
* Emergency vehicle priority handling
* Queue-based traffic management
* JavaFX GUI
* Telegram bot notifications
* Real-time intersection monitoring

## Technologies Used

* Java
* JavaFX
* Maven
* Data Structures (Queue, Priority Queue)
* Telegram Bot API

## Project Structure

* **Model** – Traffic lights, vehicles, directions
* **Service** – Simulation engine and intersection logic
* **GUI** – JavaFX interface
* **Telegram Integration** – Alert notifications

## How to Run

```bash
git clone <repository-url>
cd trafficLightSimulator
mvn javafx:run
```
